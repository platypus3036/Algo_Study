## 📚 문제별 토론 및 회고
### 📝 크레인 인형 뽑기
- **문제 링크**: [바로가기](https://school.programmers.co.kr/learn/courses/30/lessons/64061)
- **난이도**: **Lv.1**
- **주요 접근법 요약**: 
    - zip과 언패킹을 이용해 가로 배열(board)을 세로 배열로 전환하여 풀이.
    - moves 배열은 1-based 인덱스이므로, 배열 접근 시 -1 처리에 주의.
    - 배열을 변환하지 않고 2중 for문에서 board[y][x] 순서를 바꿔 탐색하는 방법도 가능.
    - 스택(Stack)을 바구니로 활용하고, isEmpty()와 peekLast()로 마지막 인형을 확인.
    - 인형을 뽑은 후에는 해당 board의 위치를 0으로 만들어줘야 함.
    - 같은 인형이 터질 때 사라지는 인형은 2개씩 카운트해야 함.

### 📝 어두운 굴다리
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/17266)
- **난이도**: **Silver IV**
- **주요 접근법 요약**: 
    - 필요한 최소 가로등 높이를 이분탐색으로 찾음.
    - ①굴다리 시작점, ②굴다리 끝점, ③가로등과 가로등 사이, 세 가지 경우로 나누어 필요한 높이를 계산.
    - max() 함수를 이용해 세 경우 중 가장 큰 값을 최종 높이로 결정.
    - 가로등이 1개인 경우를 예외로 처리.
    - 두 가로등 사이 거리를 2로 나눈 값을 올림 처리할 때, Java에서는 부동소수점 오류를 피하기 위해 (거리 + 1) / 2 와 같이 정수 연산을 활용.
    - 두 가로등 사이 거리가 홀수/짝수인지 판별하는 대신, 거리 / 2의 결과가 정수인지 소수인지로 필요한 높이를 계산.

### 📝 나무 재테크
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/16235)
- **난이도**: **Gold III**
- **주요 접근법 요약**: 
    - 문제의 N, M, K 값과 시간 제한을 고려하여 시뮬레이션으로 접근.
    - 시간 복잡도를 줄이기 위해 봄/여름, 가을/겨울을 각각 하나의 루프로 묶어서 처리 시도.
    - 봄에 나이가 어린 나무부터 양분을 먹는 규칙은 우선순위 큐(PriorityQueue)를 사용하면 효율적으로 구현 가능.
    - 우선순위 큐를 순회할 때는 우선순위가 보장되지 않는 for-each문 대신, poll()을 사용해 원소를 꺼내야 함.
    - 나무의 상태를 업데이트할 때 기존 리스트를 직접 수정하기보다, 변경된 상태를 새로운 리스트에 담은 후 기존 자료구조를 교체하는 방식이 더 간단하고 효율적일 수 있음.

## 🚀 KPT 회고 (Keep, Problem, Try)
### Keep (유지할 점)
- 다양한 자료구조와 알고리즘을 실제 문제에 적용하는 연습을 지속적으로 할 것
- 구현 과정에서 예외 처리와 언어별 특이점에 대한 주의 습관 유지

### Problem (개선할 점)
- 인덱스 처리 실수, 자료구조 변환 과정에서의 버그 발생 빈도 줄이기
- 우선순위 큐 등 라이브러리 사용 시 동작 방식에 대한 이해 부족 개선

### Try (다음에 시도할 점)
- 배열 변환 없이 인덱스 조작만으로 문제를 해결하는 방식 더 연습
- 이분탐색, 우선순위 큐 등 알고리즘적 접근법을 다양한 문제에 적용해보기
- Java와 Python 등 여러 언어로 동일 문제를 구현해보고 차이점 정리
