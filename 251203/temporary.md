# 📝 251203 임시 메모
### 파이프 옮기기 1
- N이 그렇게 크지 않아서 DFS로 풀어보았으나, 시간초과가 났음
- DP로 바꾸어서 푸는 것을 선택
- DP = 3중리스트를 만들어서, x, y, 파이프의 위치에 따른 경우의 수를 저장

- 반드시 x와 y의 좌표가 증가하기 때문에 방문처리를 할 필요가 없음
- BFS로 풀어보려 했으나, 검사로직이 복잡해서 답이 잘 안나오고 시간초과가 나서 DP를 사용

- 앞으로의 경로는 현재 상태에서만 결정 가능하기 때문에, 중복을 제거할 수 있음
- 단순 dfs 탐색은 너무 많은 경우의 수가 나와서, 계산이 불가능
