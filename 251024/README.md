## 📚 문제별 토론 및 회고

### 📝 색종이 만들기
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/2630)
- **난이도**: 실버 2
- **주요 접근법 요약**: 분할정복과 재귀를 활용한 풀이. 전체 영역이 같은 색이 아니면 4등분하여 재귀적으로 탐색하며, N=1일 때 종료. 시작점을 (0,0)에서 전체 길이의 절반씩 이동하며 각 영역을 검증
- **토론 내용 및 피드백**: 
  - DFS 재귀 방식과 while + stack 방식 두 가지 구현 방법 논의
  - 이중 for문에서 중간 탐색 종료 시 첫 번째 for문 종료 지점에 break를 추가하여 효율적인 가지치기 구현
  - base_color를 시작 지점 색상으로 설정하고 나머지 영역과 비교하는 방식으로 같은 색 검증
  - 시간복잡도 O(N log N)으로 효율적이나 재귀 사용으로 메모리 제한 주의 필요

### 📝 헌내기는 친구가 필요해
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/21736)
- **난이도**: 실버 2
- **주요 접근법 요약**: BFS를 활용한 그래프 탐색 문제. 시작점 'I'에서 상하좌우로 이동하며 벽이 아닌 공간을 탐색하고 만날 수 있는 사람 'P'의 수를 카운트
- **토론 내용 및 피드백**: 
  - 초기에 string 사용을 고려했으나 8byte 메모리 사용으로 배제하고 일반 delta 탐색 방식 적용
  - BFS와 DFS 중 선택에 대한 혼란이 있었으나, 두 방법 모두 적용 가능한 전형적인 탐색 문제로 확인
  - queue와 deque를 활용한 BFS 구현 연습
  - 시작 지점 'I' 탐색 시 입력 단계에서 미리 찾아두는 최적화 방법 논의

### 📝 테트로미노
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/14500)
- **난이도**: 골드 5
- **주요 접근법 요약**: 완전탐색 구현 문제. DFS로 4칸을 연결하여 탐색하되, 십자 모양(ㅗ, ㅜ, ㅓ, ㅏ)은 DFS로 만들 수 없어 별도 함수로 예외 처리. 테트로미노의 모든 회전 및 대칭 경우를 고려하여 최댓값 계산
- **토론 내용 및 피드백**: 
  - 초기 BFS 접근 시도 후 완전탐색 구현으로 방향 전환
  - 시간복잡도 O(N×M) ≈ 250,000으로 2초 제한 내 충분히 통과 가능함을 확인
  - DFS 탐색 depth를 4로 제한하여 테트로미노 형태 생성
  - ㅗ 모양 예외 처리를 위해 4가지 케이스(ㅗ, ㅜ, ㅓ, ㅏ) 별도 함수로 구현
  - 방문 체크 배열(visited)을 활용한 백트래킹 구현으로 중복 방지
  - 실수하기 쉬운 문제이므로 19가지 경우의 수를 정확하게 코딩하는 것이 중요

## 🚀 KPT 회고 (Keep, Problem, Try)

### Keep (유지할 점)
- 재귀와 분할정복 문제에서 base case와 시작점 설정을 명확히 하는 습관
- 이중 for문에서 효율적인 가지치기를 통한 시간복잡도 개선 노력
- BFS/DFS 탐색 문제에서 visited 배열과 queue/stack 자료구조 활용 능력

### Problem (개선할 점)
- BFS와 DFS의 선택 기준에 대한 이해 부족으로 초기 접근에서 혼란 발생
- 복잡한 구현 문제에서 예외 케이스를 놓치기 쉬운 점
- 메모리 사용량 고려 부족 (string vs 기본 자료형 선택 등)

### Try (다음에 시도할 점)
- 탐색 알고리즘 선택 기준을 명확히 하고, 문제 특성에 따라 BFS/DFS를 빠르게 판단하는 연습
- 완전탐색 문제에서 모든 경우의 수를 체계적으로 나열하고 검증하는 습관 들이기
- 재귀 문제 풀이 시 메모리 제한과 스택 오버플로우 가능성을 미리 고려
- 구현 문제에서 예외 케이스를 사전에 파악하고 별도 처리 방안 마련하기
