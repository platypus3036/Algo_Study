### N과 M (4)
- itertools.combinations_with_replacement을 이용하면 중복조합을 간단히 구할수는 있음
- 재귀로 함수를 돌면서, 원소가 M개일 때 return하는 식으로 풀어보았음(DFS)

- 백트래킹, 완전탐색, for문으로 풀어보았음
- M과 N이 최대 8이므로 백트래킹으로 풀어도 시간복잡도가 초과되지 않음

- DFS를 이용해서 for문을 중첩시켜 풀면 바로 풀 수 있음


### 과일 탕후루
- 슬라이싱으로 범위를 하나씩 설정해서 풀어보는 방법, idx 리스트를 만들어서 전체 수의 종류를 판별하는 방법을 사용했으나, 둘 다 시간초과가 나옴

- 슬라이딩 윈도우 알고리즘 구조를 이용하면 쉽게 구할 수 있음(투포인트)

- deque와 set을 이용하여 풀어보았으나 시간초과
- 윈도우 길이를 계속 갱신하면서 풀어보았음
- 딕셔너리를 사용해야 하는 이유: key값을 알면 value를 얻을 때 get함수를 사용하면 시간복잡도를 크게 줄일 수 있음(O(1))
  
### 이중 우선순위 큐 다국어

- pq(heapq)를 2개를 사용해서, 각각 오름차순과 내림차순으로 정렬해서 뽑으면 구현할 수 있을것이라 생각
- 정렬된 상태를 항상 유지하는것이 가능하다면, 최댓값과 최솟값을 뽑아내면 가능
- LinkedList를 사용해야하는지 고민
- treeset을 사용 -> 실패

- 최댓값을 제거하는 역할을 하는 리스트와, 최솟값을 제거하는 역할을 하는 리스트 총 2개를 만들어서 각각 기능을 실행
- 리스트가 2개이기 때문에, 한곳에서만 제거가 이루어지고 다른 곳에서는 제거가 되지 않을 수 있음
- -> 이를 체크하기 위해 검증용 딕셔너리를 만들어야 함!
  - 딕셔너리의 key에는 수가, value에는 수의 개수가 들어가고, value가 0이 된다면 딕셔너리 자체에서 제거
- Java에는 TreeMap이라는 기능이 있는데, 최대와 최소를 각각 찾을 수 있음
