# 🗓️ 251107 스터디 회고

## 🎯 이번 주 스터디 목표 및 주요 학습 내용
- 그리디 알고리즘, 우선순위 큐(힙), 유니온 파인드 등 다양한 알고리즘 문제에 대한 접근법을 학습하고, 각 자료구조의 특성과 효율적인 사용법을 익혔습니다. 또한, 문제 풀이 과정에서 시간 복잡도를 고려한 입력 방식의 중요성을 확인했습니다.

## 📚 문제별 토론 및 회고
### 📝 잃어버린 괄호
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/1541)
- **난이도**: Silver II
- **주요 접근법 요약**: 식의 값을 최소로 만들기 위해 그리디 알고리즘을 사용했습니다. '-' 부호를 기준으로 문자열을 분리하고, 첫 번째 숫자 덩어리에서 나머지 덩어리들의 합을 모두 빼는 방식으로 최솟값을 계산했습니다.
- **토론 내용 및 피드백**: '-'가 처음 등장한 이후의 모든 숫자는 사실상 빼는 것과 같다는 아이디어가 핵심이었습니다. 덧셈 연산을 먼저 수행하여 괄호로 묶는 효과를 내는 원리를 적용했습니다. 탐색 기준을 부호가 아닌 인덱스로 할 경우의 효율성에 대한 논의도 있었습니다.

### 📝 최소 힙
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/1927)
- **난이도**: Silver I
- **주요 접근법 요약**: Python의 `heapq` 라이브러리를 사용하여 최소 힙을 간단히 구현하고 문제를 해결했습니다. `heapq.heappush`로 원소를 추가하고 `heapq.heappop`으로 가장 작은 값을 추출했습니다.
- **토론 내용 및 피드백**: `heapq`를 사용하지 않고 정렬된 리스트로 직접 구현하려 했으나 실패한 경험을 공유했습니다. 이 과정에서 `heapq`는 루트 노드의 최솟값만 보장하고 모든 노드가 정렬된 상태는 아니라는 특징을 다시 확인했습니다. 또한, 백준과 같은 코딩 테스트 환경에서는 시간 초과를 피하기 위해 `int(input())` 대신 `sys.stdin.readline()`을 사용하는 것이 유리하다는 점을 인지했습니다.

### 📝 로고
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/3108)
- **난이도**: Gold III
- **주요 접근법 요약**: 여러 사각형들의 연결 관계를 파악하기 위해, 두 사각형이 완전히 분리되었는지 혹은 하나가 다른 하나를 완전히 포함하는지를 판별하는 함수를 만들었습니다. 이를 바탕으로 `Union-Find` (혹은 Kruskal 알고리즘)을 이용해 겹치는 사각형들을 하나의 그룹으로 묶어 총 연결 요소의 개수를 세는 방식으로 접근했습니다.
- **토론 내용 및 피드백**: 한 사각형이 다른 사각형 안에 완전히 포함되면 연결되지 않은 것으로 간주하는 조건 처리가 중요했습니다. 처음에는 접근법을 떠올리기 어려웠으나, 사각형들의 연결 관계를 그래프의 연결 요소 문제로 치환하여 생각하니 해결의 실마리를 찾을 수 있었습니다. DFS를 이용한 풀이도 가능하지만, 구현이 더 복잡할 것으로 예상되어 `Union-Find`를 선택했습니다.

## 🚀 KPT 회고 (Keep, Problem, Try)
### Keep (유지할 점)
- 문제에 맞는 적절한 자료구조(`heapq`)와 알고리즘(그리디, `Union-Find`)을 선택하여 적용하는 점.
- 시간 복잡도를 고려하여(`sys.stdin.readline`) 보다 효율적인 코드를 작성하려는 노력.

### Problem (개선할 점)
- 특정 라이브러리(`heapq`) 없이 자료구조를 직접 구현하는 데 어려움을 겪는 점.
- 복잡해 보이는 문제(예: 로고의 DFS 접근)에 대해 시도하기 전부터 어렵게 느끼는 경향.

### Try (다음에 시도할 점)
- '로고' 문제에 대해 DFS를 이용한 풀이를 직접 시도해보기.
- `heapq`를 사용하지 않고 리스트를 이용하여 직접 최소 힙의 동작 원리를 구현해보는 연습.
