# 📝 251216 임시 메모
### 원판 돌리기
- 원형 큐를 이용하려고 했으나, 시간복잡도가 너무 커질것 같아서 다른 방법을 사용
- 리스트를 직접 회전시키는 것이 아닌, 회전시 시작 인덱스를 저장하는 식으로 구현
- 원형큐처럼, 연결된 인덱스를 계산  // (j + 1) % M

- 각 deque에 대해서 index로 접근하여 회전시킴
- 배열을 사용하면서, 메모리 재사용을 고려
- 변화가 필요한 요소들을 boolean으로 따로 검사
- 모든 원판에서 인접 여부를 봐야 하였음

- 체크 비열을 만들어서, 지워야 할 위치를 따로 배열에 표시
- 회전 시 슬라이싱을 이용해 새로운 리스트를 재할당해주었음
- 큐를 사용하지 않고도 풀 수 있음
