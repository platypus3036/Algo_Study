## 📚 문제별 토론 및 회고
### 📝 보물
- **문제 링크**: [바로가기](https://www.acmicpc.net/problem/1026)
- **난이도**: Silver IV 
- **주요 접근법 요약**: 
  - S의 값을 최소로 만들기 위해서는 **A 배열의 최댓값과 B 배열의 최솟값을 곱하는 방식**으로 역순 매칭해야 함.
  - 문제 조건에 'B 배열을 정렬하지 말라'는 언급이 있으나, 결과적으로 구해야 하는 것은 **함수 S의 최종값**뿐이므로 계산 편의를 위해 **B 배열을 정렬하여 풀어도 무방**함.
- **토론 내용 및 피드백**: 
  - **조건의 재해석**: 문제에서 제시된 제약 조건(B 정렬 금지)이 실제 결과값 도출에 영향을 주는지 파악하는 것이 중요했음. S값만 출력하면 되므로 내부적인 정렬은 허용됨.
  - **심화 사고**: 만약 S값이 아니라 **조건에 맞게 재배열된 A 배열 전체를 출력**해야 하는 문제였다면, B의 원래 인덱스를 기억해야 하므로 난이도가 훨씬 상승했을 것임.
