## 🚀 KPT 회고 (Keep, Problem, Try)

### Keep (유지할 점)
- 문제별 핵심 로직과 구현 방법을 명확히 분석하고 기록하는 점
- 각 문제풀이에 대해 주석 및 코드 샘플을 공유하여 이해도를 높임

### Problem (개선할 점)
- 난이도별로 시간 계획을 구체적으로 세울 필요가 있음
- 일부 문제에서 시간 복잡도에 대한 고려 부족으로 최적화 미흡

### Try (다음에 시도할 점)
- 더 어려운 문제 도전 및 재귀, 그리디, DP 등의 고급 알고리즘 적용 연습
- 구현 시 클래스 설계 및 함수 분리를 통한 코드 재사용성 강화
